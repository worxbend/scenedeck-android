# Codebase review — 2026-09-30

Reviewed the application shell, background service/widget/navigation, all feature
modules, core repositories/models/storage/OBS client, design system and build/CI
configuration. This review follows the persistent broadcast-status change.

## Changes

- The persistent bar receives streaming and recording state from the shared session
  feed. OFF AIR stays compact; only an active stream reveals performance metrics.
  Live/record elapsed times, stream reconnecting and paused recording remain visible
  across tabs. Unknown outputs never become a guessed OFF AIR state.
- Telemetry isolates failed readings, responds to output events immediately and
  prevents older in-flight polls from overwriting newer events.
- Mixer actions report sanitized failures instead of throwing unhandled coroutine
  exceptions. Canceled fader gestures restore the exact previous OBS volume.
- Connection attempts have request-specific outcomes; profile replacement does not
  shut down the background service through a transient disconnect. Connection
  notifications say Connected rather than implying that a broadcast is live.
- Output confirmations belong to a session; switching/disconnecting invalidates old
  consent. Registry import size and write failures are handled explicitly.
- Scene graph refresh and overlapping-cycle detection are corrected. Local curation
  survives connections to different scene collections. Failed old mixer writes cannot
  undo newer successful values. Doctor transport failures stay distinct from findings.
- Inventory/settings writes surface sanitized failures, and Quick Edit remains
  scrollable on short screens with many sources.
- Meter background geometry and disabled T-bar motion follow the design contract.
- CI retains individual module SARIF reports and includes dependency review in its gate.

## Verification

Regression tests cover state transitions, unknown outputs, standby metric visibility,
failed actions, canceled gestures, connection attempts and stale-session consent.
Updated rendered previews cover standby, live, recording and simultaneous outputs in
light/dark themes. The final verification result is recorded in HARDENING.md.

## Current limitation

Connection parsing supports IPv4 and DNS hosts; IPv6 QR authorities are not supported.
